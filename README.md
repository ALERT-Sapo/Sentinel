# ACLS Clinical Training Tools
**UCI Health · ALERT Team**

A growing collection of web-based clinical training tools designed to help
bedside nurses make faster, more confident decisions during acute cardiac
events — before the rapid response or code team arrives.

These tools exist because the gap between knowing ACLS and acting on it in
real time is wider than most hospitals measure. A nurse who can identify a
rhythm but freezes on the next step, or who can't distill a report down to
what the team actually needs to hear, costs a patient critical seconds.
This project is an attempt to close that gap through accessible, low-barrier
education that staff can return to as often as they need.

## Tools

**ACLS Rhythms Quiz**
An interactive rhythm recognition quiz built with a simulated ZOLL monitor
aesthetic. Presents cardiac rhythms with animated EKG traces and tests
identification with immediate feedback and scoring.

**ACLS Clinical Decision Walkthrough**
A scenario-based reference covering the full response pathway for acute
cardiac and peri-arrest presentations — including shockable and
non-shockable rhythms, symptomatic and asymptomatic bradycardia, SVT,
junctional rhythms, and the full spectrum of AV blocks. Each scenario
walks through the decision points a nurse actually faces in real time,
not just the algorithm on paper.

**Case Studies**
Full clinical scenarios pulled from a randomized pool, each built around
a specific presentation with a defined number of decision points. Cases
can be run individually or pulled at random for unpredictable practice —
closer to how these presentations actually show up on the floor than a
fixed study order allows.

**SBAR Practice Scenario**
A drag-and-drop exercise that breaks down what's actually necessary when
reporting up to the primary team or activating rapid response. Presents
a pool of clinical information and asks the nurse to sort what belongs
in the report from what doesn't — built around the real skill gap, which
isn't knowing SBAR as a format but knowing what to cut under pressure.

## Usage

Live at: https://alert-sapo.github.io/Sentinel/

To deploy your own copy: download the HTML files and host them on any
static web server or GitHub Pages instance. No build process required.
